# Питомец Финни — Android-приложение (Kotlin + Jetpack Compose)

Функциональный прототип по техническому заданию Департамента финансов города Москвы (2026):
игровой сервис для формирования базовых финансовых навыков у детей 7–11 лет.

## Состояние (v0.5.0)

- ✅ Скелет Gradle: модули `app`, `core:economy`, `core:data`, `core:design`
- ✅ Игровая экономика (`core:economy`): BudgetEngine, SavingsEngine, RewardEngine, PetEngine — чистый Kotlin, **23 юнит-теста**
- ✅ Room-схема (`core:data`): профиль (с возрастной группой), периоды, транзакции, прогресс заданий + DAO + репозиторий (БД v2, миграция 1→2)
- ✅ Тема и компоненты (`core:design`): шрифт ≥16 sp, элементы ≥48 dp (ТЗ п. 3.6)
- ✅ Онбординг, создание питомца: имя, выбор персонажа (3 анимации: Девочка · худи, Девочка · лапки, Мальчик), выбор возраста 7–9 / 10–11 лет
- ✅ Главный экран: анимированный питомец **с прозрачным фоном** (animated WebP, ImageDecoder API 28+), настроение/сытость с максимумами, баланс, накопления
- ✅ Игровой цикл «недели»: план бюджета (план vs факт), магазин (Продукты восполняют / Улучшения поднимают максимум, строго по порядку), накопления и цели, задания (1 на тему в день; для 10–11 лет — 3 задания повышенной сложности)
- ✅ Проигрыш (показатель до 0) с экраном «Играть снова», победа после покупки всех 5 улучшений
- ✅ Достижения (8) и трофеи за крупные покупки; автоматический доход 30 🪙 в начале недели (кроме первой)
- ✅ Полное прохождение до победы проверено автопрогоном на эмуляторе
- ✅ Раздел взрослого: сводка прогресса ребёнка и сброс прогресса с подтверждением (ТЗ п. 2.5.12)
- ✅ Демо-режим: на стартовом экране кнопка «🎬 Демо-режим: показ для коллег» — подменяет профиль готовым сценарием «середина игры» (Неделя 3, 2 купленных улучшения, исполненная цель, история транзакций, 4 из 8 достижений) для живой презентации без прохождения игры с нуля

## Сборка

Требования: JDK 17+ (встроен в Android Studio), Android SDK 34 (платформа android-34 установлена на машине).

```bash
./gradlew :app:assembleDebug      # debug APK
./gradlew :core:economy:test      # юнит-тесты экономики
./gradlew :app:assembleRelease    # релиз (потребуется подпись — см. ниже)
```

Важно: проект лежит в папке с кириллицей (`Работа/Финансы`). JVM на Windows читает
@argfile тестовых worker в CP1251, а Gradle пишет его в UTF-8 — из-за этого classpath
тестов ломается. Поэтому build-директории перенаправлены в ASCII-путь
`C:/Users/vovas/.finni_build` (см. `build.gradle.kts`, переопределяется
`-Pfinni.build.root=...`). В репозиторий-сборку для команды рекомендуется клонировать
в ASCII-путь (например, `C:\StudioProjects\Finni`) — тогда обход не нужен.

## Структура

```
app/                    — приложение: MainActivity, навигация, экраны
  src/main/assets/content/ — учебный контент (15 заданий, товары, цели, словарь)
  src/main/res/raw/     — анимации персонажей (animated WebP с альфой, 121 кадр)
core/economy/           — чистая игровая логика (без Android-зависимостей)
core/data/              — Room: entities, DAO, БД (v2), ProfileRepository
core/design/            — FinniTheme, типографика, кнопки ≥48 dp
```

## Подпись релиза (для RuStore)

Keystore создан: `finni-release.jks` (alias `finni`, действует ~27 лет), параметры — в `keystore.properties`
(файл с паролями не коммитить). Подпись подключена в `app/build.gradle.kts` (signingConfigs → release).

```bash
# пересоздать ключ (если нужно):
keytool -genkeypair -v -keystore finni-release.jks -alias finni \
  -keyalg RSA -keysize 2048 -validity 10000
./gradlew :app:assembleRelease   # → app-release-v0.5.0.apk (подписан)
```

## Установка на устройство

```bash
adb install -r app-debug-v0.5.0.apk      # отладочная
adb install -r app-release-v0.5.0.apk    # подписанная релизная (для раздачи)
```

Важно: debug- и release-сборки подписаны разными ключами — поставить одну поверх другой
нельзя, сначала нужно удалить приложение (прогрессы на устройстве сотрутся).
