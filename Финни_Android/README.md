# Питомец Финни — Android-приложение (Kotlin + Jetpack Compose)

Функциональный прототип по техническому заданию Департамента финансов города Москвы (2026):
игровой сервис для формирования базовых финансовых навыков у детей 7–11 лет.

## Состав репозитория

- `Финни_Android/` — исходный код (модули `app`, `core:economy`, `core:data`, `core:design`) и готовые APK
- `Сопроводительная_документация_Финни.docx` (+ исходный `.md`) — сопроводительная документация по разделу 5 ТЗ (12 обязательных пунктов)
- `Данные_о_программе_Финни.md/.docx`, `Текст_презентации_Финни.md/.docx`, `Требования_к_презентации.md` — презентационные материалы (раздел 4 ТЗ)
- `Финни_план_реализации_Kotlin_Compose.md/.docx` — исходный план реализации
- `TZ_незакрытые_требования.md` — журнал закрытия выявленных несоответствий ТЗ
- `qa_render/` — PDF-превью документов для экспертизы
- `demo_video.mp4` — резервная видеозапись демонстрации (ТЗ 4.1)

## Сборка

Требования: JDK 17+ (встроен в Android Studio), Android SDK 34 (платформа android-34 установлена на машине).

```bash
./gradlew :app:assembleDebug      # debug APK
./gradlew :core:economy:test      # юнит-тесты экономики (23 теста)
./gradlew :app:assembleRelease    # релиз (потребуется подпись — см. ниже)
```

Важно: проект лежит в папке с кириллицей (`Работа/Финансы`). JVM на Windows читает
@argfile тестовых worker в CP1251, а Gradle пишет его в UTF-8 — из-за этого classpath
тестов ломается. Поэтому build-директории перенаправлены в ASCII-путь
`C:/Users/vovas/.finni_build` (см. `build.gradle.kts`, переопределяется
`-Pfinni.build.root=...`). В репозиторий-сборку для команды рекомендуется клонировать
в ASCII-путь (например, `C:\StudioProjects\Finni`) — тогда обход не нужен.

## Структура

```
app/                    — приложение: MainActivity, навигация, 14 экранов
  src/main/assets/content/ — учебный контент (15 заданий, 13 товаров, 3 цели, словарь; JSON, отделён от UI)
  src/main/res/raw/     — анимации персонажей (animated WebP с альфой, 121 кадр)
core/economy/           — чистая игровая логика (без Android-зависимостей)
core/data/              — Room: entities, DAO, БД (v3), миграции 1→2→3, ProfileRepository
core/design/            — FinniTheme, типографика, кнопки ≥48 dp
```

## Подпись релиза (для RuStore)

Keystore: `finni-release.jks` (alias `finni`, действует ~27 лет), параметры — в `keystore.properties`
(файл с паролями не коммитить, сам keystore тоже не коммитить). Подпись подключена в `app/build.gradle.kts` (signingConfigs → release).
Внимание: в ранних версиях keystore случайно попал в git — в v0.6.0 создан **новый** ключ, старый отозван; пароли изменены.

```bash
# пересоздать ключ (если нужно):
keytool -genkeypair -v -keystore finni-release.jks -alias finni \
  -keyalg RSA -keysize 2048 -validity 10000
./gradlew :app:assembleRelease   # → app-release-v0.6.0.apk (подписан)
```

## Установка на устройство

```bash
adb install -r app-debug-v0.6.0.apk      # отладочная
adb install -r app-release-v0.6.0.apk    # подписанная релизная (для раздачи)
```

Важно: debug- и release-сборки подписаны разными ключами — поставить одну поверх другой
нельзя, сначала нужно удалить приложение (прогрессы на устройстве сотрутся).
