# Питомец Финни — интерактивный прототип

Игровой прототип приложения по финансовой грамотности для детей 7–11 лет
(техническое задание Департамента финанса города Москвы, 2026).

Прототип воспроизводит обязательный сценарий ТЗ в браузере: создание питомца,
план бюджета по 3 направлениям, задания, покупки, накопления на цель,
итоги периода, раздел для взрослого и демонстрационный режим.
Состояние хранится локально (localStorage), регистрация и сервер не нужны.

## Запуск

Требуется Node.js 18+.

```bash
npm run dev          # http://127.0.0.1:7100/
npm run dev -- --port 3000   # другой порт
```

На телефоне: компьютер и телефон в одной Wi-Fi сети, затем
`npm run dev -- --host 0.0.0.0 --port 7100` и открыть `http://<IP компьютера>:7100/`.

## Проверка экономики

```bash
node tests/smoke.js  # 25 дымовых тестов игровой логики
```

## Демонстрационный сценарий (для показа коллегам)

1. Онбординг → «Понятно, начнём!».
2. Создание питомца: имя ребёнка, имя питомца, 3×3×3 варианты внешности.
3. Главный экран: баланс 40 🪙, настроение/сытость, активное задание.
4. «+20 ежедневный доход» (в демо-режиме безлимитно).
5. «План бюджета»: распределить монеты, проверить контроль суммы и остаток, подтвердить.
6. «Покупки»: купить корм (обязательное) и игрушку; попробовать купить при нехватке — увидеть объяснение.
7. «Задания»: пройти любое из 6, включая ошибочный вариант — объяснение показывается всегда.
8. «Накопления»: выбрать цель, пополнить, снять — с показом последствий.
9. «Завершить период»: таблица план vs факт, объяснение состояния питомца, балл периода.
10. Повторить 4–5 периодов — питомец вырастет на новую стадию.
11. Закрыть вкладку и открыть заново — прогресс сохранился.
12. 🔒 на главном экране → удерживать кнопку 3 секунды → раздел взрослого:
    прогресс, включение демо-режима, сброс тестового профиля.

## Структура

```
index.html, app.js, style.css   — приложение (без сборки, без зависимостей)
server.js                       — статический сервер (npm run dev)
content/                        — учебный контент (6 заданий, 8 товаров, 3 цели, словарь)
tests/smoke.js                  — дымовые тесты игровой экономики
проверка_экрана.png             — скриншот первого экрана
```

Контент редактируется JSON-файлами в `content/` без изменения кода
(см. карту контента: ../Финни_контент/КАРТА_КОНТЕНТА.md).

## Ограничения прототипа

- Это браузерная модель игрового цикла, а не финальная Android-сборка.
- Питомец собран из эмодзи/CSS вместо иллюстраций.
- Цель — показать механику, контент и обратную связь до нативной разработки
  (Kotlin + Jetpack Compose, план: ../Финни_план_реализации_Kotlin_Compose.md).
